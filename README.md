# Apprendre le français – Objectif B2

Site gratuit pour préparer le niveau B2 demandé pour la naturalisation : test de niveau, parcours A2 → B2, écoute, lecture, écrit, oral, vie en France, révisions espacées.

- `contenu.js` : tout le contenu (ajouter un module = ajouter un objet).
- `app.js` : le fonctionnement. La progression est gardée dans le navigateur (aucune donnée envoyée).

En ligne : https://rsantia96-hash.github.io/Apprendre-le-fran-ais/
